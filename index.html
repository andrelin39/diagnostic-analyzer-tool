3分組診斷指標比較
選擇分組方式：
公式說明
Sensitivity= TP / (TP+FN)
Specificity= TN / (TN+FP)
PPV= TP / (TP+FP)
NPV= TN / (TN+FN)
Accuracy= (TP+TN) / N
LR+= Sensitivity / (1−Specificity)
LR−= (1−Sensitivity) / Specificity
Cohen's κ= (Po−Pe) / (1−Pe)
Kappa 判讀：Landis & Koch (1977). Biometrics 33(1):159–174
